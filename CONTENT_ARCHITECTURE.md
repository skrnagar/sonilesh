# EHS360 Marketing Content Architecture

## Voice

- Clear, executive-ready, operationally credible
- Prefer verbs of control: report, assess, authorize, verify, close
- No hype, no fake social proof, no certification theatre

## Global messaging

| Layer | Copy |
|---|---|
| Brand | EHS360 |
| Tagline | One Platform. Complete EHS Control. |
| Support | From the field to the boardroom. |
| Promise | Unify incidents, risk, permits, inspections, CAPA, training, and analytics in one multi-tenant SaaS platform. |

## Homepage sections (order)

1. **Hero** — brand-first, tagline, one support line, CTA group (Request Demo / Sign In), full-bleed product viz
2. **Trust strip** — industries as text (Construction, EPC, Power, Renewables, Manufacturing, Oil & Gas, Infrastructure, Mining, Logistics)
3. **Problem** — fragmented tools, weak field capture, no closed-loop CAPA, limited board visibility
4. **Platform overview map** — Field → Operations → Risk → Assurance → Leadership
5. **Product showcases** — Dashboard, Risk, CAPA, Field device
6. **Field experience** — mobile-first capture, offline-aware language without overclaim
7. **Workflow lifecycle** — Report → Investigate → CAPA → Verify → Close
8. **Multi-tenant enterprise** — org isolation, sites/projects, RBAC, entitlements
9. **Configuration** — categories, workflows, forms without code claims
10. **Analytics** — leading/lagging indicators, filters, exports (capability-level)
11. **AI-ready** — assistive potential; no “autonomous EHS” overclaim
12. **Security** — isolation, auth, audit trail; **no fake certs**
13. **Industry solutions** — links into vertical pages
14. **Pricing teaser** — Contact Sales / Custom
15. **Resources teaser** — placeholders
16. **Final CTA** — Request a demo

## Page content patterns

### Platform / Features / Enterprise / Security

Problem → capability pillars → viz → proof points (factual product truths) → CTA

### Solutions hub + industry pages

Industry challenges → how EHS360 maps → recommended modules → CTA  
No invented customer names or metrics.

### Modules hub + module pages

Module purpose → workflow → key capabilities → related modules → CTA

### Pricing

Tiers framed as **Contact Sales** / **Custom Enterprise** — no dollar amounts.  
Emphasize plans, entitlements, usage limits as product concepts.

### Resources

Placeholder cards: implementation guides, module overviews, field adoption tips (coming soon).

### Request demo / Contact

Name, work email, company, industry, message/role. Success state local only unless wired later.

## Claim guardrails

| Allowed | Forbidden |
|---|---|
| Multi-tenant isolation, RLS-oriented architecture language | SOC 2 / ISO / GDPR badges |
| Configurable RBAC & entitlements | Fake logos / Fortune 500 lists |
| AI-ready / assistive framing | “AI replaces HSE managers” |
| Contact Sales pricing | Invented price tables |
| Industry text strip | Partner logo walls |
